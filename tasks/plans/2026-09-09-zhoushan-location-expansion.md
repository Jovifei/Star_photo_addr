# 舟山海岛热门机位扩展计划（v1.0.8）

## 基线与范围

- 基线：`main@21051b7409e34ec5ef578e7b27a2233a08723e90`（已部署 v1.0.7）。
- 分支：`codex/zhoushan-location-expansion-20260909`。
- 目标：为星空摄影观测平台补充公开资料可核对的舟山/嵊泗热门银河、晚霞与海岸机位。
- 不做：不改评分算法、天气接口、CloudSea 语义或用户已有 LocalStorage 候选；不把旅游宣传语转写成概率承诺。

## 实施项

- [x] 以官方文旅/政府资料、地图 POI 和公开摄影报道交叉核对候选，去重并记录交通、潮汐、夜间开放和安全限制。
- [x] 在 `catalog.json` 新增 5 个通用摄影候选，使用保守 Bortle 参考值和可追溯坐标。
- [x] 将其中代表性海岛机位加入首页默认精选；保持用户自定义候选不被覆盖。
- [x] 更新版本号至 v1.0.8、根目录/`docs` 更新日志、工程修改记录、测试夹具和相关动态计数。
- [x] 先跑新增回归与 `npm run check`，再跑 live smoke、数据源检查和浏览器门禁。
- [ ] 提交 `codex:` commit，推送分支，等待 CI 后合并 `main` 并按部署文档发布；发布后核对公网版本、API 和页面。

## 验收标准

- 新增 ID、名称、坐标唯一且在中国范围内；5 个点位均有非空机位说明和可达性/安全提示。
- `FINDER_LOCATIONS`、默认精选、更新日志和版本测试对 v1.0.8 一致。
- 原有 252 个点位、评分和 CloudSea 54 个点位行为不变；不覆盖用户保存的候选。
- 本地质量、实时数据、数据源探针、E2E 与 CI 通过后才允许部署；公网 `/healthz` 的版本和构建 SHA 与合并主干一致。
