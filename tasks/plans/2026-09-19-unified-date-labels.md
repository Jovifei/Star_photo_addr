# 2026-09-19 四页面日期可读性统一

## 目标

让主页、观星候选对比、火烧云、云海四个入口中的日期选择/日期状态都能同时读出相对语义和实际日期：`今日 · 9月19日 周六`、`明日 · 9月20日 周日`、`后日 · 9月21日 周一`。七日夜间列表也统一为 `9月19日 周六`，不再使用容易误读的 `9/19` 或仅“周五夜”。

## 行动项

- [ ] 先补共享日期格式和四页面红测，确认当前只改了云海/旧格式的遗漏。
- [ ] 在火烧云、云海日期选择器中显示相对标签 + 月日 + 星期。
- [ ] 在主页逐夜时间轴、评分时间、地图评分时间说明和候选对比日期 tabs 中统一使用月日 + 星期。
- [ ] 运行日期单元测试、四入口 focused E2E、响应式检查和完整静态门禁。
- [ ] 更新 lessons 与 Review；本轮只修改展示文案，不改变日期计算、评分、数据源或 URL 状态。

## 验收标准

- 四个入口在同一运行日期下均能读出今日/明日/后日的实际月日和星期。
- 主页七日 tabs、候选对比 tabs、评分时间文案不再只显示数字日期或“周X夜”。
- 跨午夜夜间含义仍保留，日期键和数据请求不改变。
- 375、390、414 和短横屏下标签不产生页面级横向溢出。
