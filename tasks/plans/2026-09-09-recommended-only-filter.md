# v1.0.9 顶部推荐地点筛选开关（2026-09-09）

## 目标

把已有的“仅显示达到推荐门槛的地点”偏好放到顶部命令状态栏的“我的位置”后面，让用户进入页面后无需打开右侧设置即可切换地图地点筛选。沿用现有推荐门槛、评分档位、LocalStorage 和 marker 过滤契约，不改评分算法或数据源语义。

## 验收标准

- 顶部命令栏中控件顺序为搜索框 → “我的位置” → “仅显示达到推荐门槛的地点”。
- 开关默认沿用现有偏好（新浏览器关闭），点击后持久化并立即影响观星地点 marker、当前显示数量与视口推荐。
- 推荐门槛仍由右侧“推荐门槛”滑块决定；数据不足点位在开启时不被误当作合格点位。
- 桌面与移动端关键宽度无页面级横向溢出，既有设置面板与推荐档位筛选保持可用。
