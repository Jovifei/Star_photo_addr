# 云海验证标签口径纠正

原报告和原始数据均保留。本补充不重算或覆盖旧报告，纠正其结果可以支持的结论范围。

此前把KMWN的BKN///或OVC///、水平能见度较高、正文无FG，作为“广阔脚下云层”正例，口径过宽。[NOAA AWC](https://aviationweather.gov/help/data/)明确该编码云高指云底；[MWO观察员说明](https://mountwashington.org/thoughts-from-the-newest-observer/)也说明云可以部分或全部位于山顶以下。它不能单独证明云顶也低于机位，更不能直接证明可拍云海。

因此旧的30正例、命中/漏报等数字只适用于当时定义的编码代理端点，不能当作实际云海发生率或摄影命中率。明确的低能见度FG/VV遮挡反例仍有独立观测支持，其高分安全审查继续有效。

[MWO的解码实例](https://mountwashington.org/null-304/)确认TPS LWR SCT050描述下方云层的云顶；[NOAA词典](https://forecast.weather.gov/glossary.php?word=LWR)确认LWR为Lower。但未找到该站特殊云顶数字基准的明确规程，不能将推断的MSL高度和山顶间距冒充已核实实测。

本阶段增加真正的视觉目标：公开Sonnblick Observatory相机，3106m，47.053979N/12.957484E，朝200度。源[历史页](https://www.foto-webcam.eu/webcam/sonnblick/2026/09/15/1200)、拍摄元数据和三个原图服务器GMT修改时间相互支持档案时钟为UTC+02；明确这是源时钟证据支持的映射，非JPEG内嵌EXIF证明。每张图仍逐一核对时间，不把缺图当晴天。

开发集固定九月1–30日当地08/11/14/17时。独立留出仍为整段八月及十月11–20日，对应时刻保持相同；候选冻结前不查看/标注留出图片。图像由不知道预报结果的标注者按固定指南分为：明显可见的广阔机位以下云海、明确遮挡/无可见云海、未知。模糊云墙、镜头冰雪、不可判断高度的云和夜景不强制归类。

该来源的公开单图使用条款要求注明foto-webcam.eu并链接来源；认证按日ZIP接口不使用、不绕过。原图仅存批准下载目录，不向GitHub发布相机照片。相机数据、标签、源码与预测分别留SHA记录。

新的科学结论必须同时报告视觉云海正例捕获、高分误报、未知与缺测、源时钟资格，以及适用机位/视场。现有675项工程检查通过不能替代这些验证。本候选尚未通过科学发布门槛，不部署。
