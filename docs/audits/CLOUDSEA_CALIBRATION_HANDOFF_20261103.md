# 云海命中率独立真值校准与远端长任务接力（2026-11-03）

## 一、当前最终目标

建立基于真实高山机位观测（山顶/山谷独立相机影像与气象站实况）的**云海预测命中率定标闭环**。根本性解决：
1. **高分误报**：模型预测 94 分以上，现场山顶却被重云或浓雾包裹，看不见云海；
2. **低分漏报**：现场出现壮观云海，但模型预测只有 30 多分甚至因数据不足而暂缓推荐。

使云海页面展示的 0–100 指数从“未经实测校准的数值网格公式”演进为“经过概率校准与真值验证的高置信度摄影决策指数”。

## 三、现在卡在哪里

1. **数值模式网格尺度与局地微地形脱节**：
   - 当前云海预测依赖 GFS 0.25°（水平分辨率约 25 km）单一站点网格。高山峡谷地带夜间及清晨容易积聚局地辐射雾或浅层逆温云，但在粗网格中被平滑成了晴空（地面低云预报为 0%），导致大面积低分漏报（正例被打入 10–25 分甚至暂缓）。
2. **高分误报压制与正例捕获率的极端拉锯**：
   - 在复现 94 分误报时发现：原算法只取最低层 cloud deck，忽略了包裹山顶的第二层云；为压制多层云包裹误报，现行保守规则收紧了逆温与上界要求。
   - 结果导致在 164 时次的 Sonnblick 独立留出集上，≥60 分推荐直接归零，导致高分精确率不可估计、正例捕获率不足 40%（未达到既定科学发布门槛）。
3. **国内典型机位高频实拍标签稀缺**：
   - 现有回放数据主要依靠海外公开相机，华东（天目山系、黄山、三清山）与川西（牛背山、鱼子西、巴朗山）复杂山地环境缺乏成体系的时序实拍真值支持。

## 五、下一步应该做什么（交给远端 ChatGPT 的长任务执行大纲）

远端 ChatGPT 网页端负责宏观审核、方案设计、长任务执行与代码提交。建议长任务聚焦于以下三个核心模块展开：

### 任务 1：设计并实现 Phase 2 周边地形/谷底多点感知采样
- **核心逻辑**：打破单点粗网格依赖。以山峰为中心，向周边 8–15 km 辐射采样 4 个谷底/迎风坡参考点。
- **特征提取**：
  1. 计算“山峰海拔 - 谷底海拔”落差；
  2. 提取谷底网格的近地面饱和度（露点压差 < 1.5°C 或 RH > 92%）；
  3. 结合山顶网格晴空条件（山顶高度以上无厚云遮挡）与近地层逆温特征（气温随高度增加），作为局地谷雾填满山谷的强信号，弥补 GFS 粗网格低云 0% 的缺陷。

### 任务 2：借鉴开源气象算法补充物理约束
- **借鉴开源项目**：
  - **FogPy / Satpy**：借鉴双通道红外亮温差分算法（如 AHI 11μm 与 3.9μm 亮温差）识别低空浅层辐射雾顶的边界条件。
  - **MetPy LCL**：根据近地面温湿计算精确的抬升凝结高度（LCL），约束初始云底范围。

### 任务 3：严格留出验证与自动化测试闭环
- **发布硬门槛**：
  - 留出样本至少 10 个独立正例；
  - ≥60 推荐至少 20 个时次；
  - 高分精确率 ≥ 75%；
  - 包含暂缓在内的正例捕获率 ≥ 40%；
  - 高分未知占比 ≤ 20%；
  - 遮挡误报率 ≤ 10%。
- 远端完成方案设计与代码实现后，运行全套测试验证，并将完成的代码与证据提交到 GitHub 仓库分支，最后交回本地 Codex 接收与部署。
