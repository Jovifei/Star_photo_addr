## [v1.0.0] - 2026-09-05

### 🎉 里程碑正式版发布
本次发布统一了全站设计语言、根治了气象数据上游限流冲垮离线缓存的连锁漏洞，全面提升了高山观测与天文摄影选址的稳定性与专业质感。

### 🎨 视觉与交互重构 (UI / UX)
- **双倒角悬浮舱体统一**：火烧云与云海工作台全面统一对齐为「深空观测站·双倒角悬浮舱体」设计规范（四周 `14px 18px 16px` 呼吸留白、地图与右侧地点面板均为 `border-radius: 14px`，施加 1px 半透青色微光边框与 48px 深层环境光阴影）。
- **左上角版本记录**：全站顶栏左上角品牌处新增版本徽标 `v1.0.0`，支持点击弹出交互式版本变更日志面板。
- **文字重叠彻底清除**：重构地图顶部药丸工具栏与告警横幅的纵向空间布局，消除窄屏与移动端下的文字遮挡。
- **星空窗口表格粘性固定**：表格首列地点名称添加 `position: sticky; left: 0;`，横向滑动后半夜数据时地点名固定不被裁切，无数据时以 `—` 优雅展位。
- **图例与暗框优化**：修复云海图例左侧文字被视口边缘裁切的问题；移除未配置天地图时的多余暗框提示。

### 🛡️ 数据稳定性与快照装甲 (Data Reliability)
- **快照装甲保护机制 (Snapshot Armor)**：在 `/api/fireglow/snapshot` 增加覆盖防护，当新拉取的有效站点数不足时（如上游返回 HTTP 429），严禁覆盖磁盘与内存中的已有有效数据，自动降级回退现存离线快照，彻底消灭“因限流导致全站数据不足、点位全灰”的恶性循环。
- **前端雪崩防范**：移除火烧云页面在检测到数据降级时自发触发全量 242 站点并发刷新的逻辑，避免页面访问瞬间冲击上游配额。
- **Worker 预热温和化**：后台定时任务预热时移除强刷参数，优先复用有效持久化数据。

### ⛰️ 名山海拔与空间近邻容灾 (Elevation & Spatial Fallback)
- **权威名山高程推导**：新增名山高程词典与 5km 空间反距离推算模块，解决搜索或点选“太子尖”、“牵牛岗”、“天荒坪”、“牛背山”等名山时海拔显示为 0m 的问题。
- **120km 近邻空间气象兜底**：当搜索未缓存的特定坐标遇到上游 429 限流时，自动平滑调取 120km 范围内最近站点的逐小时气象数据保底返回，杜绝前端崩溃为 429 报错与 0 分。

### 🚀 自动化交付与运维 (DevOps)
- **自动化静默部署脚本**：新增并完善 `scripts/deploy-remote.ps1`，支持 SSH KeepAlive 保活、远端自动拉取、Docker 镜像构建与健康检查全流程自动化。
