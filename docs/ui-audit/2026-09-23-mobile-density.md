## 实际问题与修复

1. **专题页头占用过高**：生产云海在384×760浏览器模拟视口中 header=239.26px，地图起点346.59px。旧路由 CSS 的 `.segmented:nth-child(2)` 指定第二行，使已收起的日期仍独占一行。增加语义 data-mode，并在共享 compact 样式中明确 grid 位置；日期、时段与调整入口同排。
2. **栏目选择视觉权重过大**：统一四个入口的 compact 导航为13px标签和选中下划线，移除大胶囊背景、阴影与双层品牌文案。48 CSS px 的操作区域保持。平板768–1199px标题/导航同排。
3. **长期解释占据首屏**：云海/火烧云模型原理改为原生 details/summary。短说明保留条件指数与概率区别；展开可读完整原文。请求失败、stale与数据不足状态不折叠。
4. **地图与数据的垂直比例**：手机地图52svh、平板46svh且封顶480px，短横屏保留64svh规则；排行和逐小时内容更早进入视口，整页仍自然纵向滚动。
5. **抽屉内部数据横向裁切**：真实应用中的 `.mobile-map-panel-pane` 隐式auto网格列被长内容撑到约747px。375px回归新增断言复现 body横向溢出382px（RED）。显式 `minmax(0,1fr)` 后同一用例PASS，浏览器384px下摘要宽364px、body溢出0。
6. **设置展开额外空行**：展开后的收起按钮与晨昏选择同排；手机日期2列、平板4列，刷新独立排列。
