# UI/UX Pro Max 页面优化审计

更新时间：2026-08-06

## 采用的方法

本轮使用 `ui-ux-pro-max-skill` 的可搜索设计知识库，按“无障碍 → 触控与交互 → 性能 → 响应式 → 视觉系统 → 图表”的优先级审查现有 React 页面。生成的项目设计系统保存在：

- `design-system/star-photo-planner/MASTER.md`

知识库给出的页面模式是 Real-Time / Operations Dashboard，密度 7/10、动效 3/10。生成器的浅色蓝色模板没有直接覆盖现有产品，而是翻译为深夜观测台语义：青色只表示可执行动作，紫色表示天文信息，绿/黄/红只表示判断状态。

## 已落地

- 全局：增加跳到主要内容的 skip link、统一可见焦点环、动态视口高度和移动端横向溢出保护。
- 导航与筛选：当前页面使用 `aria-current`；7/14 天、星空/云海、观测夜使用 `aria-pressed`；核心按钮达到 44px 触控高度。
- 弹窗与抽屉：补充 `dialog` / `aria-modal` / 标题关联，打开时自动聚焦，Tab/Shift+Tab 保持在弹层中，关闭后把焦点还给触发控件。
- 地图：增加键盘可访问的“已保存点位快速选择”，作为 Leaflet 图形标记的文本替代入口；计算、错误和保存反馈使用 live region。
- 数据可读性：分数、坐标、天气数字使用等宽数字和 tabular numerals；小字号统一提升；状态仍有文字，不只靠颜色。
- 图表：ECharts 改为详情抽屉打开后动态加载；图表容器提供中文可访问名称；ECharts ARIA 与纹理辅助开启。
- 动效：所有交互保持 150–300ms，按下反馈不改变布局；继续尊重 `prefers-reduced-motion`。
- 响应式：自动化脚本覆盖 375、768、1024、1440 四个关键宽度的页面级横向溢出检查。

## 有意没有采用

- 没有在线加载 Google Fonts。国内网络、隐私和可用性风险高于收益；CSS 保留 Fira Sans/Fira Code 作为优先候选，并提供完整的系统字体回退。
- 没有增加持续闪烁的“实时”动画。天气不是秒级流数据，制造实时感会误导并增加视觉噪声。
- 没有把生成器的浅色模板覆盖现有深色观测主题；这会破坏当前夜间摄影使用场景和全站一致性。
