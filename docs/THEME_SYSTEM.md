# Observatory Theme v2

## 设计目标

全站像一台完整的夜间观测仪器，而不是若干来源不同的深色页面。信息优先，装饰克制；青色表示可执行的观测动作，紫色只用于天文事件，绿/黄/红仅表示结论状态。

## 核心令牌

- 背景：`--bg-deep` / `--bg`，用于页面与地图底层。
- 面板：`--surface` / `--surface-2` / `--surface-3`，用于卡片层级，不为不同页面另造颜色。
- 文字：`--text`、`--muted`、`--muted-2`。
- 观测主色：`--cyan`；天文强调：`--violet`。
- 状态：`--good`、`--warn`、`--bad`，不作为普通装饰色。
- 圆角：面板 16px、控件 10px、胶囊 999px。
- 阴影：`--shadow-panel` 与 `--shadow-float` 两级。

## 组件规则

- 顶部/底部导航：活动项使用青色浅底和同色文字，不用实心大色块。
- 主按钮：青色渐变胶囊；禁用状态降低透明度，不改变语义颜色。
- 数据面板：统一半透明靛蓝表面、细边框和 16px 圆角。
- 排名：每个点位是独立的 10px 圆角行卡，悬停只做轻微抬升。
- 表格：表头使用同一深靛蓝，隔行色来自 `surface-2`，不再单独使用地图紫。
- 地图：搜索框、弹层、右侧检查器与全站面板一致；底图本身保持低对比。
- 状态标签：描边胶囊，颜色严格对应 good/warn/bad/muted。
- 手机：面板保留 14px 圆角；地图满宽；底栏使用相同毛玻璃表面。

## 验收清单

- 1440×1000 与 390×844 均无非预期横向滚动。
- 四个主导航页面的背景、卡片、按钮和标题层级一致。
- 地图搜索框不遮挡缩放控件，手机定位按钮保持 44px 左右点击区域。
- 状态色不承担普通装饰，色弱用户仍能从文字读懂结论。
- 键盘焦点使用统一青色双层焦点环。
- `prefers-reduced-motion` 下关闭非必要动效。
