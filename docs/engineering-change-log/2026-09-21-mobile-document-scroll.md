# 手机和平板整页滚动修复

## 原因

app-shell 沿用桌面 100vh/overflow:hidden，顶部筛选全部展开，手机只能在剩余小区域里滚动。上一版仅验证抽屉宽度，遗漏真实滑动与信息优先级。

## 修改

- 小于 1200px 使用原生整页纵向滚动，页头与筛选随页面离开视口。
- 首页和暗夜选址默认折叠「时间与地点筛选」，可展开调整所有原有参数。
- 地图保留稳定高度；单指默认滑动页面，按「移动地图」后可拖地图，完成后恢复页面滑动。三个地图实现共用同一个控制组件。
- 移动工具详情提升为视口底部面板，不再困在地图剩余空间里。
- 云海、火烧云排行移除局部高度限制；日期分为三天一行、总览一行。
- 时间轴时间、播放、夜数分行排列，完整显示来源说明；不加入 scroll 监听器或强制平滑滚动。

## 验证与边界

- npm run check：lint、类型检查、60 文件 / 352 项 Vitest、生产构建通过。
- Chromium 360/390/768/1024 单指触摸事件：文档向下滚动、页头退出视口、无横向溢出、筛选和地图模式切换通过。
- 手机布局/面板/专题详情 11 passed / 2 项非手机条件跳过。
- 桌面/手机工作台、筛选、推荐、响应式回归 22 passed / 16 项设备条件跳过。
- 视觉：实际查看手机首页、滚动后画面、云海日期与排行布局、768px 平板首页。
- 检测到一加 7 Pro 在线，但自动审批拒绝 ADB 打开网页操作（blocked by policy）。真机安装/滑动 NOT_RUN，不以模拟器结果替代。
