# 2026-11-22 地图瓦片重试

地图重绘会先卸载旧瓦片。此前提示把卸载当作恢复，导致重试请求仍在等待时提示消失。修复后按图层、坐标和瓦片元素跟踪替换。原坐标仍在当前视图时，对应替换瓦片实际加载成功才清除这条失败记录。视图切走、瓦片取消或图层移除时清理不再需要的记录。

PR #71 首次 Chromium 全套发现飞行动画尾段的同类问题。追踪中旧瓦片在缩放过渡期间卸载，同坐标的替换瓦片到动画结束才开始请求。补充的 Chromium 事件记录显示，缩放中途会提前出现一次 `moveend`。修复分别跟踪移动和缩放，在它们都结束时清理没有替换的瓦片。单元回归固定提前 `moveend` 的顺序，并验证健康图层的加载不能清除提示。

390px 回归在旧构建上挂起替换响应后失败。新构建在 Chromium 和 WebKit 验证了挂起时保留提示、替换返回 503 时继续显示、同一张瓦片加载 PNG 后才清除提示。云海卡片、条件指数和原始采集时间仍可读，快照请求计数保持 1。

构建中出现过两类失败。TypeScript 无法把空格分隔的 Leaflet 事件名匹配到瓦片事件重载，改用具名事件映射后通过。Next.js 16.4.3 首次编译完成后以 `SecurityFatalError` 退出，原样重跑 `npm run check` 最终退出码为 0。`npm audit --omit=dev --audit-level=high` 退出码为 0，报告为 1 个中危依赖、0 个高危、0 个严重。依赖升级作为单独的变更处理。
