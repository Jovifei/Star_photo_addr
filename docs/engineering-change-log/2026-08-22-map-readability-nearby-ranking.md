# 工程修改跟踪：地图可读性、暗夜说明与附近排行

> 日期：2026-08-22  
> 基线：`main@5d8682dc77afa0e870bc108614720d0b141f42f0`  
> 目标分支：`main`（按用户要求直接提交）

## 1. 修改目的

针对实际运行截图中的以下问题进行可远端完成的修复：

- 左上地点筛选和右上云量面板字体过小、遮挡地图、无法移动；
- 总云量/高中低云以四块按钮展示，可比较性不足；
- 天顶亮度、Bortle 显示“无数据”，但没有解释“未安装”和天气接口故障的区别；
- 无天地图令牌时难以确认中国方向；有令牌时没有加载官方境界图层；
- 地图点击都叫“取样点”，缺少区域线索；
- 观星计划缺少以当前点为中心的 10/50/100/200 km 排行；
- 海拔可能混入厘米或异常值，缺少统一展示边界；
- 今夜观测、暗夜选址和观星计划的职责不够直观；
- 星空、云海、晚霞的产品入口缺少明确边界。

## 2. 本次完成

### 2.1 面板移动与缩放

新增 `MapPanelManager`：

- 观星地点、云量与图层、暗夜图层三块面板可单独选择；
- 90%–135% 滑动调整；
- 拖动标题/色带移动；
- 恢复默认位置；
- 布局保存到当前浏览器 localStorage；
- 不写入 URL，不影响其他用户和服务端状态。

### 2.2 云量通道视觉

保留单选和原有 ARIA 语义，把四个方块改为纵向百分比条：

- 总云量、高云、中云、低云各自颜色；
- 条长反映 0–100%；
- 数字、当前通道与色阶仍保留；
- 不改变 Open-Meteo 数据和评分算法。

### 2.3 暗夜数据说明

- 侧栏的“天顶亮度 / 波特尔”在栅格缺失时直接显示“未安装”，不再含糊地显示“无数据”；
- 未安装时明确显示“暗夜数值栅格 / 未安装”；
- 弹窗解释这是许可驱动的安全降级；
- VIIRS 视觉夜光仍可用，但不能冒充 Bortle/SQM；
- 新增 `docs/DARK_SKY_DATA_SETUP.md`，列出目录、构建变量和验证步骤。

### 2.4 行政边界

- 配置 `NEXT_PUBLIC_TIANDITU_TOKEN` 时，叠加天地图 `ibo_w` 官方境界和 `cia_w` 中文注记；
- 本地授权边界包按 country / province / prefecture 分级显示，并使用层级不同的虚线、粗细和透明度；
- 无令牌时增加“中国”方向标签和边界状态提示；
- 未使用来源不明的 GeoJSON 绘制国界。

### 2.5 取样点与海拔

- 地图点击默认名称改为“省份/区域附近取样点”或带坐标的取样点；
- 名称来自最近整理点的近似上下文，不冒充逆地理编码；
- 海拔统一为米；厘米样式值在合理范围内转换，超出 -500..9000 m 显示待核验；
- 主侧栏坐标信息也使用统一海拔格式。

### 2.6 观星计划附近排行

新增折叠面板：

- 半径 10/50/100/200 km；
- 当前夜晚评分优先，其次距离、Bortle、海拔；
- 展示省份、区域、直线距离、海拔、Bortle、分数和推荐档位；
- 点击候选后用现有 planner URL 协议重新载入该地点；
- 明确直线距离不等于道路距离。

### 2.7 工作区与产品边界

- `/sites` 虽然复用主地图引擎，但标题和说明明确切换为“暗夜选址 · 长期暗空基础”；
- 今夜观测强调天气和连续窗口；
- 观星计划强调附近排行与多夜比较；
- 新增 `docs/product/WORKSPACE_ARCHITECTURE.md`；
- 云海保留实验能力，晚霞只进入规划文档，不把未完成入口放入正式导航。

### 2.8 自动刷新

参考页面的“每两小时自动刷新”本质是服务器预生成快照。逐星现有 Worker 默认 `SNAPSHOT_INTERVAL_MS=1800000`，即 30 分钟，频率更高；本次保留该策略，不改成更慢的两小时。
