# v1.0.5 独立终审补充记录（2026-09-07）

在 `fix/release-integrity-v1.0.5` 已完成首轮完整 CI 后，对页面显示与数据语义继续做独立复审，补充收口以下问题：

- 云海窗口只使用同一小时内关键字段全部有效的时次，避免跨小时拼接出不存在的条件向量。
- 云海 `peakTime` 改为逐小时计算后选最高条件指数，不再取窗口中点。
- 低云不足时不再展示启发式生成但没有实际意义的云底/云顶/相对高差。
- 云海工作区移除“逆温层/气压层高度”误导文案；当前 Beta 明确为 surface cloud + 2m RH + wind + terrain 启发式。
- 云海 stale、refreshError 与请求失败在页面显式可见，不再只写浏览器 console。
- 云海与火烧云插值色面明确为点位条件指数 IDW 插值，不是卫星/雷达连续像素场。
- 火烧云朝霞详情修复硬编码“日落/正西”文案和兜底方向；晨间使用日出/正东语义。
- 火烧云三日总览详情使用真正获胜窗口所在日期计算太阳事件，不再固定使用三日第一天。
- 火烧云详情缺失云量不再显示成 0% 并误判地平通道通透。
- 生产 OpenGraph 域名改为 `photo.joviluma.com`，并避免在 root layout 强制 `/` canonical 影响子工作区。
- `/integration-plan` 仅开发环境可见；生产环境返回 404/noindex。

本补充不包含旧 Planner/CSS 删除；该结构性清理继续留给后续 v1.0.6，避免扩大 v1.0.5 数据真实性修复面的回归半径。
