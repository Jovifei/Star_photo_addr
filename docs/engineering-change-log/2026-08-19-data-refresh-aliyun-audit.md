## 1. 审计目标

再次检查浏览器、Next.js 同源 API、外部天气/卫星/光污染提供方、缓存与人工刷新之间的完整链路，重点覆盖：

- Open-Meteo 总云量、低云、中云和高云；
- NASA GIBS Himawari 卫星云图与 VIIRS Black Marble；
- VIIRS 2023 第三方光污染 WMTS；
- 观星地点评分快照；
- `refresh=1`、并发合并、冷却、旧数据回退和请求取消；
- Docker Compose 与阿里云 ECS 长时间运行时的资源和失败边界。

## 2. 发现的问题

### 2.1 云量网格刷新会自我取消

`CloudLayer` 在刷新开始时先把 `cloudGrid` 清空。该状态变化会再次触发同一个 effect，第二次请求会取消第一请求，形成一次刷新中的重复请求、地图闪空和不必要的上游压力。

### 2.2 卫星产品切换可能保留上一产品帧

云图切换到夜光目录失败时，旧云图帧可能继续留在本地状态。组件原先只按模式标志判断，没有再次验证帧的 `kind`，因此存在把旧帧放到新产品语义下展示的风险。

### 2.3 GIBS 原生缩放等级没有声明

服务端选择的 GIBS matrix set 分别止于云图 Level 6 和夜光 Level 8，但浏览器图层允许直接请求更高层级。高缩放时可能请求不存在的 matrix，而不是让 Leaflet 放大最后一个有效原生层级。

### 2.4 光污染瓦片被不必要的 CORS 要求阻断

光污染图层仅作为普通 `<img>` 瓦片展示，不参与 canvas 像素读取。原先设置 `crossOrigin="anonymous"` 会强制第三方或自建 WMTS 返回 CORS 响应头；没有该响应头的有效图片会被浏览器判为加载失败。

### 2.5 自定义光污染模板缺少构建前/运行时校验

错误的 `NEXT_PUBLIC_LIGHT_POLLUTION_TILE_URL` 可能缺少 `{z}/{x}/{y}`、使用非法协议、包含未知占位符或把账号密码写入 URL。页面和服务端探测原先都会直接尝试使用它，错误信息不够明确。

### 2.6 重型观星评分刷新冷却可被参数变化绕过

观星快照的精确缓存键包含 `days` 和 `focusTime`。若强制刷新冷却也使用该精确键，调用方可以不断改变时次或范围，从而重复触发 242 个地点的天气任务。旧兼容接口 `/api/stargazing-finder/weather` 也缺少等价的冷却与并发合并。

## 3. 修复方案

### 3.1 云量刷新

- 为请求增加“上下文 + 地图边界”签名；
- 同一个签名只保留一条请求；
- 地图移动时只取消真正过期的边界请求；
- 同地点、同模型、同夜晚人工刷新时保留旧画布，成功后原子替换；
- 失败时明确提示“已保留上一次结果”，不把地图先清空。

### 3.2 卫星与夜光

- 服务端返回后再次验证 `kind/source/observed/isForecast/tileTemplate`；
- 模式变化时旧产品目录不参与渲染；
- 云图原生最大缩放设为 6，夜光设为 8；
- 地图可继续放大到 18，由 Leaflet 对最后有效原生瓦片做 overzoom。

### 3.3 光污染 WMTS

- 去掉普通图片瓦片不需要的 `crossOrigin`；
- 增加模板校验：必需坐标占位符、HTTP(S)、无嵌入凭据、无未知占位符；
- 浏览器和 `/api/data-status` 使用同一校验逻辑；
- 连续瓦片失败仍按既有阈值进入 `degraded`，下一张成功瓦片可自动恢复。

### 3.4 刷新保护

- 精确快照缓存键继续保留 `days/focusTime`，保证响应内容正确；
- 强制刷新冷却改为更宽的 `date + model` family key；
- 变化 `days/focusTime` 不再绕过冷却；
- 冷却期有旧快照时直接返回并标记 stale/refresh-cooldown；
- 冷却期缺少精确快照时允许从普通缓存生成，但不会绕过上游缓存；
- 兼容天气接口增加模型校验、超时、同请求合并、刷新冷却、脱敏错误和响应头。

## 4. 新增验证

- 光污染模板合法/缺占位符/非法协议/嵌入凭据单元测试；
- 卫星产品隔离、无效帧和 GIBS 原生缩放单元测试；
- 观星快照精确键与刷新 family key 单元测试；
- Playwright：人工刷新期间旧云量画布持续可见，并且多地点网格只发起一次强制刷新请求；
- Playwright：第三方光污染瓦片在没有 CORS 响应头时仍能加载。

## 5. 部署边界

- `/healthz` 只检查应用进程，不依赖第三方数据；
- `/api/data-status` 检查天气、卫星目录、光污染瓦片和可选本地资产；
- 第三方光污染 WMTS 仍建议在长期生产中替换为有许可、自托管或受控 CDN 源；
- `NEXT_PUBLIC_*` 为构建时变量，修改后必须重新构建镜像；
- 本次不修改天气评分公式，不把 VIIRS 视觉图层伪装为现场 Bortle/SQM。
